# AI 短影音自動化 Prompt 包 v1

> 示範版本。正式版會隨頻道影片更新，用同一個 Email 重新下載即可拿到新版。

使用方式：把整段 prompt 貼給 Claude Code、ChatGPT 或任何對話式 AI，把 `【】` 裡的內容換成你自己的。

---

## 1. 選題：一個關鍵字 → 10 個題目

```
你是短影音選題編輯。主題是【AI 自動化】，目標觀眾是【想用 AI 省時間的上班族】。
請給我 10 個 60 秒短影音題目，每個題目附：
- 開頭 3 秒的鉤子句（不超過 15 字）
- 觀眾看完能得到的一個具體結果
- 為什麼這題會被分享（一句話）
避免空泛的「AI 很厲害」型題目，每題都要能在影片裡實際示範。
```

## 2. 腳本：60 秒口播稿

```
用以下題目寫一支 60 秒口播稿：【題目】
結構：
1. 0–3 秒：鉤子，直接講結果或反常識
2. 3–45 秒：3 個步驟，每步一句「做什麼」＋一句「為什麼」
3. 45–55 秒：示範成果
4. 55–60 秒：CTA「完整 prompt 放在簡介連結，免費拿」
語氣口語、短句，每句不超過 20 字，總字數 250 字以內。
```

## 3. 分鏡：腳本 → 畫面清單

```
把下面的口播稿拆成分鏡表，用表格輸出欄位：
秒數 | 口播句 | 畫面內容 | 螢幕字幕（≤12字） | 需要的素材
每 2–4 秒一格。畫面優先用「螢幕錄影」和「成果畫面」，少用抽象素材。
【貼上腳本】
```

## 4. 字幕檢查

```
檢查以下字幕檔：錯字、專有名詞大小寫（Claude Code、ChatGPT、YouTube）、
每行是否超過 16 個中文字、斷句是否在語意中間。
只列出需要修改的行，格式：行號 | 原文 | 建議。
【貼上 SRT】
```

## 5. 標題與簡介

```
為這支影片寫：
- 3 個標題（≤ 30 字，含數字或具體結果）
- 簡介 3 行：第一行重述結果、第二行列重點、第三行放「完整 prompt：【連結】」
- 5 個 hashtag
影片內容：【貼上腳本】
```

## 6. 卡住時：整理成求助單

```
我在做【目標】時卡住了。
我做了：【步驟】
看到的錯誤：【完整錯誤訊息】
我的環境：【作業系統 / 工具版本】
請先判斷最可能的 2 個原因，再給我一個最小的驗證步驟，不要一次給整套重寫。
```
