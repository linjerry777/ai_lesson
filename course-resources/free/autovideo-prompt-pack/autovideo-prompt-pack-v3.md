# AI 短影音自動化 Prompt 包 v3

JERRY.AI 頻道（訊號滿格、麻糬QQ）每天做片用的同一套規則，整理成可以直接貼給 Claude Code、ChatGPT 或任何對話式 AI 的 prompt。

用法：把 `【】` 換成你的內容，整段貼上。建議照順序用，一支片走完 1 → 6。

> 2026-10-22 實測：6 組都在同一個對話裡實際跑過一次（Claude），都能得到可直接用的結果。第 1 組要查當天新聞，請用能上網搜尋的 AI（ChatGPT、Gemini、Claude 開啟搜尋）。

---

## 0. 先記住的四條規則

1. **第 1 秒就給最有感的結果**，不要放標題卡、不要自我介紹。
2. **每一句旁白都要讓觀眾多懂一件事**，沒有就刪。
3. **每一句先選「鏡頭」再寫字幕**：數字用重擊、日期用時間軸、條件用勾選卡、比較用長條。
4. **一次只改一個變因**，才看得出數據為什麼變好或變差。

---

## 1. 選題（新聞類）

```
你是短影音新聞編輯。請幫我找【日期】當天或前一天，由官方來源（公司部落格、官方 changelog、官方文件）公布的【領域，例：AI 與開發工具】新聞，挑 3 則（不足就 2 則，不要硬湊）。

規則：
- 第三方報導只能當線索，事實一律回到官方原文。
- 第一則（開場）必須是觀眾切身的：變便宜/免費、影響他的裝置、帳號或工作流程。公司投資、併購、小眾工具放第二三則。
- 每則給我：官方網址、公布日期、2–4 條能直接對應原文的事實（附原文句子）、以及「不能說」的誤解（例：預覽≠正式、官方測試≠本人實測、輸出上限≠上下文長度）。
- 查不到官方原文的，直接說查不到，不要補。
```

## 2. 選題（娛樂類：○○人圖鑑）

```
幫我想 5 個「○○的人分四種，你是哪一派？」短片題目，主題要人人都有經驗（手機、上班、睡前、外送、考試、旅行這類日常）。
每個題目給：
- 四種人的名稱（每個 2–5 字，好笑、好記）
- 每一種人「畫得出來」的一個笑點畫面（具體道具、數字或動作，不能只是形容詞）
- 一句冷開場：全片最誇張的那一刻，10 個字內，最好帶一個數字
我做過的主題有：【已做過的主題】，不要重複。
```

## 3. 腳本＋鏡頭（逐句）

```
把下面的內容寫成【40–50 秒新聞／25–32 秒圖鑑，二選一】直式短片腳本，輸出成表格，每一列一句：
| # | 旁白（念的稿，數字寫成中文念法） | 字幕（最多兩行） | 鏡頭類型 | 鏡頭內容 | 音效 |

鏡頭類型只能用：數字重擊、官方截圖、勾選卡、時間軸、長條比較、疊卡、斷線圖、角色反應、笑點道具、收尾。
規則：
- 第 1 句就是結論＋最大的數字（新聞）或最誇張的笑點（圖鑑）。
- 前 5 秒任何畫面靜止不超過 1.5 秒。
- 每則新聞 2–3 句：公告是什麼 → 關鍵變化 → 條件/限制 → 誰受影響。
- 圖鑑：冷開場 → 四型各一句（笑點要畫出來）→ 主持人自爆是其中兩型 → 「快標記那個…的朋友」→ 最後一句回到開場畫面。
內容：【貼上查證結果或題目】
```

## 4. 發布前檢查

```
這是我剛做好的短片腳本與畫面描述（或抽格圖）。請逐項檢查並列出要改的地方：
1. 前 5 秒有沒有空畫面、只有標題、或靜止超過 1.5 秒
2. 字幕有沒有超過兩行、擋到臉或擋到證據
3. 每個數字、日期能不能在我提供的來源找到；圖解有沒有標「示意」
4. 有沒有把官方測試說成自己實測、把預覽說成正式
5. 片長是否在目標範圍
最後給一句結論：可以發 / 不能發（原因）。
【貼上腳本或描述】
```

## 5. 標題與說明

```
幫這支短片寫 3 個 YouTube Shorts 標題（≤40 字）和一段說明。
- 新聞：<產品> <最重要的變化>、<第二則>、<第三則>｜M/D 科技三則
- 圖鑑：<主題>的人分四種，你是哪一派？｜<主題>人圖鑑
說明要包含：每則一行重點、官方原始網址、「AI 旁白、AI 生成角色」標示、5 個 hashtag。
不要用「震驚」「必看」這類空泛字。
【貼上腳本】
```

## 6. 數據回饋（每次只改一件事）

```
這是我最近 5 支短片的數據，欄位依序是：日期｜題目｜這次改了什麼｜24h 觀看｜48h 觀看｜平均觀看秒數
【一支一行，照上面的欄位順序貼上】
請：
1. 只根據這些數字寫觀察，樣本少就說樣本少，不要下因果結論。
2. 從「開場句型、開場長度、片長、題材類別、節奏、格式」中，建議下一支只改哪一個，為什麼。
3. 其他設定全部維持不變，列出來讓我照抄。
```
